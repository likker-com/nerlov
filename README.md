#### 🏍️ Мои увлечения и вайб:
* 🏍️ **Мотоциклы, скорость и адреналин:** Обожаю мото-культуру, рёв мотора и ощущение полной свободы на дороге. Скорость для меня — это стиль жизни!

* **🔥 Экстремальная производительность:** Моё кредо — *«Если операцию можно выполнить за 10 наносекунд вместо 100 — код должен быть переписан»*. Выжимаю максимум FPS из JVM, пишу кастомную тригонометрию FastMath, безразветвленный код и умный куллинг.
* **🎮 Разработка для Minecraft (Fabric 1.20.1 & Paper):** Создатель модификаций (**HolyOptik**, **HolyZoom**, **HolyMenu**, **HolyUtils**) и высоконагруженных серверных систем.
* **🐍 Python:** Асинхронные скрипты (AsyncIO), боты, утилиты автоматизации, парсеры и анализ данных.
* **🗄 Базы данных & Сети:** MySQL 8, Redis-кэширование, HikariCP и сетевые протоколы.
